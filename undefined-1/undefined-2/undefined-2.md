# 연수관리

교육상품관리 > 연수관리에서 연수과정을 등록 및 관리가 가능합니다.

![](<../../.gitbook/assets/image (79).png>)

![](<../../.gitbook/assets/image (80).png>)

* 필터를 활용하여 검색, 원하는 조건에 부합하는 카테고리 값 조회
* `[연수구분관리]` : 연수 등록 시 구분하는 카테고리 값 설정
* `[선택연수복사]` : 버튼 클릭 시 연수 복사하는 기능
* `[등록]` 버튼 클릭 시 연수 등록이 가능
