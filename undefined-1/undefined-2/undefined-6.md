# 인증서관리&#x20;

## 인증서 템플릿 관리

다중 수료증 기능을 사용하여 과정별 다른 수료증 템플릿을 적용할 수 있습니다.

![](<../../.gitbook/assets/attachment60a17cc3 3865 4a72 b613 36f8d7bd3a50image.png>)

### 인증서 템플릿 등록하기

![](<../../.gitbook/assets/attachmentbe80efad d667 4379 ba72 c8617af1a0c4image.png>)

![](<../../.gitbook/assets/attachmentdb8cb778 c24e 456c bbac 7350e848fc6eimage.png>)

1. \[등록] 버튼 클릭
2. 템플릿코드 및 템플릿명 작성 후 내용에 HTML 소스코드 입력
3. \[기본템플릿] 클릭 시 선택한 인증서 유형에 맞는 기본 HTML소스코드 자동 입력됨
4. \[저장] 버튼 클릭

### 템플릿 수정하기

템플릿 수정이 가능하며, 해당 템플릿을 사용하는 과정을 확인할 수 있습니다.

![](<../../.gitbook/assets/attachmentadfc0535 785a 475a a897 729a53367265image.png>)

1. \[템플릿명] 클릭
2. 내용 확인하여 수정한 후 \[수정] 버튼 클릭
3. 해당 수료증 템플릿을 사용하는 과정을 확인할 수 있습니다.
