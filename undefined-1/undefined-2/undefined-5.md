# 마켓관리

교육상품관리 > 마켓관리에서 마켓 카테고리, 상품 관리를 통해 판매 상품 등록 및 과정에 함께 판매할 상품을 관리할 수 있습니다.

![](<../../.gitbook/assets/image (94).png>)

## 마켓 카테고리 관리

### 상위 카테고리 등록

![](<../../.gitbook/assets/image (95).png>)

{% step %}

홈페이지의 상품 페이지로 이동합니다.
{% endstep %}

{% step %}
## 과정목록타입 선택

갤러리형 / 웹진형 중 선택합니다.
{% endstep %}

{% step %}
## 상품정렬순서 선택

추천순 / 최신순 / 가격 낮은순 / 가격 높은순 / 임의지정순 중 선택합니다.

{% step %}
## 홈페이지 상품 리스트에 노출할 목록 개수 설정

설정 후 \[저장] 버튼을 클릭하여 등록합니다.
{% endstep %}

{% step %}
## \[하위등록] 버튼 클릭

상위 카테고리의 하위 카테고리 등록창이 노출되어 등록할 수 있습니다.
{% endstep %}
{% endstepper %}

### 하위 카테고리 등록

사용자 사이트 > 상품 리스트의 탭별 페이지 화면 설정

![](<../../.gitbook/assets/image (97).png>)

{% stepper %}
{% step %}
## \[하위등록] 버튼 클릭

카테고리 등록창으로 이동합니다.
{% endstep %}

{% step %}
## 각 항목별 값 지정 후 등록

* 과정목록타입 : 갤러리형 / 웹진형 선택
* 상품정렬순서 : 추천순, 최신순, 가격 낮은순, 가격 높은순
* 홈페이지 상품 리스트에 노출할 목록 개수 및 메뉴 노출 여부, 탭 노출 순서 선택 설정
{% endstep %}

{% step %}
## 내용 입력 후 \[등록] 버튼 클릭

저장 완료합니다.
{% endstep %}
{% endstepper %}

### 상품 등록

![](<../../.gitbook/assets/attachment08b559e8 9352 4f8b 8f19 42a12e5ccef8image.png>)

![](<../../.gitbook/assets/attachmentfa5d40ef 98a1 4a0c aedf 8cbb4d8febc9image.png>)

![](<../../.gitbook/assets/attachment4a60619d 2196 4bb6 bb90 e7e655d2b95bimage.png>)

{% stepper %}
{% step %}
## \[상품등록] 버튼 클릭

상품 등록 페이지로 이동합니다.
{% endstep %}

{% step %}
## 각 항목 내용 기입

\*는 필수 기입 사항입니다.

* 상품판매개수 제한 : 상품의 판매개수를 제한 가능
* 이벤트 문구 / 라벨 : 썸네일 이미지 상단에 등록 가능
* 상품 이미지 : 미리보기 이미지 등록
{% endstep %}

{% step %}
## 가격 정보 기입

\*는 필수 기입 사항입니다.

* 정가: 표기될 정가
* 판매가: 실제 구매 시 지불할 금액
* 부가세면세여부: PG사와 계약된 사항에 따라 선택
* 배송료: 착불/선불 선택 및 선불 시 금액 입력
{% endstep %}

{% step %}
## 수량이 한정된 상품의 경우 상품판매 개수제한 설정

수량이 한정된 상품의 경우 해당 설정을 합니다.
{% endstep %}

{% step %}
## 옵션 사용여부 설정

옵션(사이즈/컬러 등)이 있는 상품의 경우 설정합니다.
{% endstep %}

{% step %}
## 상세 정보 입력

* 상품 설명 / 상품정보제공고시 : 내용 입력
* 추천 상품 : 설정 시 추천으로 노출되며, 라벨을 설정한 경우 라벨이 우선으로 노출됨
* 판매여부 / 노출여부 / 상태 : 설정 확인
{% endstep %}
{% endstepper %}
