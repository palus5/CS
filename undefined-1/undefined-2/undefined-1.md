# 발송관리

## 1. 메일 발송관리

엑셀 파일을 이용한 대량 발송 또는 회원그룹별 메일 발송이 가능하며, 메일 템플릿 기능을 사용하면 쉽게 메일을 작성하고 전송할 수 있습니다.

![](<../../.gitbook/assets/image (46).png>)

![](<../../.gitbook/assets/image (47).png>)

① 발송일 : 발송일 기준으로 원하는 날짜 지정

검색 : 제목/내용/발송자/회원 아이디 검색한 키워드가 포함된 메일 검색

② \[컬럼] 클릭 시 해당 컬럼을 기준으로 오름차순/내림차순 정렬 가능 (\* 수신자 컬럼 제외)

### 메일 발송 - 회원 선택

![](<../../.gitbook/assets/image (48).png>)

① \[발송] 버튼 클릭하여 메일 작성 페이지로 이동

② \[회원 선택] 탭을 선택 하여 개별발송 수신자를 선택

③ 메일 유형 : ‘수신 동의자’ 또는 ‘전체(수신 거부자 포함)’을 선택

※ 정보통신법 안내서와 정보통신법 Q\&A를 통해 해당 법령 확인

④ \[대상선택] 클릭 후 메일을 수신할 대상 선택

⑤ 메일 템플릿 선택 시 템플릿 적용되며, 템플릿 적용 후 텍스트 추가 가능

⑥ \[미리보기] 버튼 클릭 시 작성된 메일 확인 가능

⑦ \[발송] 버튼 클릭하여 이메일 발송

### 메일 발송 - 회원 그룹 선택

회원그룹 선택 이용 시 특정 그룹에 속해 있는 회원에게 메일을 발송할 수 있습니다.

![](<../../.gitbook/assets/image (49).png>)

① \[회원그룹 선택] 탭 클릭

② 메일 유형 : ‘수신 동의자’ 또는 ‘전체(수신 거부자 포함)’을 선택

※ 정보통신법 안내서와 정보통신법 Q\&A를 통해 해당 법령을 확인

③ 수신자 : 발송할 그룹 선택 (회원관리에서 그룹핑한 그룹명과 그룹에 속한 인원 수 표시)

④ 발송자 : 발신자 이메일 입력 (\* 홈페이지관리 > 사이트정보에서 변경 가능)

⑤ 제목 및 템플릿 선택한 후 내용 작성

⑥ \[발송] 버튼 클릭 시 메일 발송 완료

### 메일 발송 - EXCEL(엑셀)

엑셀 파일을 통해 메일을 일괄 발송할 수 있습니다.

![](<../../.gitbook/assets/image (50).png>)

① \[EXCEL] 탭 클릭

② \[샘플 다운로드] 버튼 클릭 후 엑셀 양식에 맞는 내용 작성한 후 저장

③ \[파일 선택] 버튼 클릭 후 작성한 엑셀 파일을 선택

④ 필요 항목을 기재한 후 \[발송] 버튼 클릭하면 회원들에게 일괄 메일을 발송

#### 사용 가능 회원 개인정보 변수

| 설명      | 변수                     |
| ------- | ---------------------- |
| 아이디     | \{{login\_id\}}        |
| 성명      | \{{user\_nm\}}         |
| 성명(마스킹) | \{{user\_nm\_mask\}}   |
| 소속명     | \{{dept\_nm\_conv\}}   |
| 기타필드    | \{{etc1\}}\~\{{etc5\}} |

## 2. 메일 템플릿 관리

소스코드를 작성하여 메일 템플릿을 작성할 수 있습니다.

![](<../../.gitbook/assets/image (51).png>)

![](<../../.gitbook/assets/image (52).png>)

① 필드 값을 설정하여 검색 가능

② 템플릿코드 : 등록 시 설정한 템플릿코드

템플릿명 : 클릭 시 수정 화면으로 이동

발송제목 : 이메일 제목 작성

③ \[EXCEL] : 버튼 클릭 시 템플릿 관리 목록 엑셀 다운로드

④ \[등록] : 버튼 클릭 시 템플릿 설정 가능

### 메일 템플릿 설정하기

![](<../../.gitbook/assets/image (53).png>)

① \[등록] 버튼 클릭

② 템플릿 코드 입력(영문 소문자, 숫자,\_ 조합)

③ 템플릿명 작성

④ 이메일 발송 제목 작성

⑤ 소스코드 작성

⑥ 상태 : ‘정상’ 또는 ‘중지’ 선택

⑦ \[등록] 버튼 클릭 시 등록 완료

## 3. 메일 시스템 템플릿 관리

학습자 설정에 따른 ‘자동 발송’ 이메일 템플릿을 관리합니다.

\[사본수신] 기능으로 메일 발송 시 발송된 이메일 사본을 확인할 수 있습니다.

![](<../../.gitbook/assets/image (54).png>)

![](<../../.gitbook/assets/image (55).png>)

① 탭 별 자동발송 이메일 템플릿 설정 가능

② \[초기화] 버튼 클릭 시 기본값 템플릿으로 초기화

③ \[수신인추가] 버튼 클릭 > 사본 메일 확인할 수신인 추가(ex : 관리자 본인)

④ 내용 : 필요한 부분 수정

⑤ 상태 : ‘정상’ 또는 ‘중지’ 선택

⑥ \[미리보기] 클릭 시 이메일 발송양식 확인 가능

⑦ 내용의 기본 값 변경 후 \[수정] 버튼 클릭

## 4. SMS 발송관리

SMS 발송 및 관리가 가능하며 개별 및 대량(엑셀 파일 이용) 발송이 가능합니다.

발신 로그 조회 및 템플릿 기능 사용으로 편리하게 SMS를 관리할 수 있습니다.

단, SMS 서비스는 부가 서비스이므로 신청 후 사용 가능합니다.

![](<../../.gitbook/assets/image (56).png>)

### SMS 리스트

![](<../../.gitbook/assets/image (57).png>)

① \[발송] 버튼을 클릭 시 등록 페이지로 이동

② \[수신자] 버튼 클릭 시 수신자 창을 오픈 및 수신동의 · 발송 여부 확인 가능

③ \[내용] 클릭 시 재발송 화면으로 이동하여, ‘동일한 내용’ 또는 ‘수정한 내용’으로 재발송 가능

### SMS 발송 - 회원선택

회원별로 SMS를 발송할 수 있습니다.

![](<../../.gitbook/assets/attachmentd2427950 91b7 4540 9d71 8eebf3047245image.png>)

① \[회원 선택] 탭 선택

② SMS유형 : ‘영리/광고성’ 또는 ‘비광고성’ 선택

③ \[대상 선택] 버튼 클릭

④ 대상 회원 목록에서 선택할 회원을 ‘더블 클릭’ 또는 ‘\[>>]’ 버튼을 클릭하여 추가\
\[선택 삭제] 버튼 클릭하여 삭제 가능

⑤ 선택 회원 목록에 추가된 것 확인한 후 \[확인] 버튼 클릭

⑥ 템플릿 사용 혹은 내용 작성 (\* 오른쪽 특수기호 문자표 선택 가능)

⑦ \[발송] 버튼 클릭

* \[발신번호]는 비즈뿌리오에서 인증 받은 번호만 사용 가능
* 번호 변경 시 비즈뿌리오에서 인증 후 맑은소프트로 문의

### SMS 발송 - 회원그룹 선택

\[회원정보관리] > \[회원그룹관리]에 등록된 그룹에게 SMS를 발송할 수 있습니다.

![](<../../.gitbook/assets/attachment0ef7645e 304e 49c4 b2cb f1d6392e321aimage.png>)

① \[회원그룹 선택] 탭 클릭

② SMS유형 : ‘영리/광고성’ 또는 ‘비광고성’ 선택

③ 발송 대상 그룹 선택

④ 템플릿 사용 혹은 내용 작성 (\* 오른쪽 특수기호 문자표 선택 가능)

⑤ \[발송] 버튼 클릭

### SMS 발송 - EXCEL(엑셀)

엑셀 파일을 통해 일괄로 SMS를 발송할 수 있습니다.

![](<../../.gitbook/assets/image (58).png>)

![](<../../.gitbook/assets/attachmentb2bf4239 c59f 46a0 9c97 00a0c02f43deimage.png>)

① \[EXCEL] 탭 클릭

② 엑셀의 경우 SMS 수신동의 여부 확인이 불가능 하여 ‘비광고성’으로 활용

③ \[샘플 다운로드] 버튼 클릭 후 엑셀 양식에 맞는 내용 작성한 후 저장

④ \[파일 선택] 버튼 클릭 후 저장한 엑셀 파일 업로드

⑤ 템플릿 사용 혹은 내용 작성 (\* 오른쪽 특수기호 문자표 선택 가능)

⑥ \[발송] 버튼 클릭

### SMS 재발송

![](<../../.gitbook/assets/image (59).png>)

① \[제목] 클릭 시 재발송 화면으로 이동

② 원하는 항목 \[탭] 선택하여 재발송 가능

③ SMS 유형은 변경 불가능

④ \[파일 선택] 버튼 클릭 후 저장한 엑셀 파일 업로드

⑤ 예약 발송 시간 설정

⑥ 내용 작성 (\* 오른쪽 특수기호 문자표 선택 가능)

⑦ \[발송] 버튼 클릭

![](<../../.gitbook/assets/image (60).png>)

![](<../../.gitbook/assets/image (61).png>)

③ 전송결과 메뉴 > 실시간 결과 조회를 통하여 발신 결과 조회 가능

## 7. 알림톡 관리

SMS 서비스 이용 시 카카오톡 알림톡 발송이 가능합니다.

알림톡 템플릿 등록 후 사용 가능합니다.

이용 시 알림톡이 선순위로 발송되며, 카카오톡이 없는 회원의 경우 SMS로 발송합니다.

![](<../../.gitbook/assets/image (64).png>)

![](<../../.gitbook/assets/image (65).png>)

① 발송일 : 발송일 기준으로 원하는 날짜 지정

검색 : 제목/내용/발송자/회원 아이디 검색한 키워드가 포함된 메일 검색

② \[EXCEL] : 클릭 시 알림톡 목록 다운로드

③ \[발송] : 클릭 시 알림톡 내용 전송 가능

④ \[내용] : 제목 클릭 시 발송 내역 확인 가능 및 재발송 가능

⑤ \[수신자] : 클릭 시 수신 회원 및 발송여부 확인 가능

## 10. 푸쉬 알림

앱 푸시 서비스 신청 시 맑은소프트 앱 푸쉬 알림 기능을 사용할 수 있습니다.

![](<../../.gitbook/assets/image (72).png>)

### 푸시 발송

![](<../../.gitbook/assets/image (73).png>)

① \[발송] 버튼 클릭

② 푸쉬유형 : 광고성과 비광고성 선택 (마케팅 수신 비동의시 발송불가)

③ 푸쉬범위 : 전체 또는 개별 선택

④ 발송대상 : 푸쉬범위 ‘개별’ 선택 시 \[대상선택] 버튼 클릭하여 대상자 추가

⑤ 예약발송 : 날짜 및 시간 선택

⑥ 제목 : 제목 작성

⑦ 내용 : 알림 내용 작성

⑧ 이동URL : 모바일 알림바에서 푸쉬 클릭 시 연결될 홈페이지 URL 등록

⑨ 이미지 파일 : \[파일 선택] 클릭 후 업로드 시 모바일 페이지 알림바 하단에 이미지 표시\
(\* 사이즈 권장 비율 : 512px X 256px)

### 푸시 재발송

![](<../../.gitbook/assets/image (74).png>)

① \[제목] 클릭 시 재발송 화면으로 이동

② \[재발송] 버튼 클릭 시 재발송 완료

③ \[삭제] 버튼 클릭할 경우 푸시 목록에서 삭제

## 11. 오픈알림관리

회원정보관리 > 오픈알림관리에서 알림 신청을 한 인원에게 메일 혹은 sms를 발송할 수 있습니다.

![](<../../.gitbook/assets/attachmentf250ab74 681e 48c0 a304 c1013ebfd3e4image.png>)

① 신청한 회원 및 신청한 과정의 정보 확인 후 체크박스로 선택

② \[메일] 혹은 \[SMS] 클릭해서 알림 발송

## 12. 학습독려관리

회원정보관리 > 학습독려관리에서 메일, SMS 선택하여 학습독려 알림 발송할 수 있습니다.

학습독려를 등록 시 등록된 학습독려명과 상태 및 상세 정보를 확인이 가능합니다.

패키지 과정을 제외한 모든 과정에서 이용할 수 있습니다.

단, SMS 발송은 부가 서비스이므로 신청 후 사용 가능합니다.

학습독려 발송 시간을 맑은소프트에게 전달해 주시면 됩니다.

![](<../../.gitbook/assets/image (75).png>)

### 학습독려 등록

![](<../../.gitbook/assets/image (76).png>)

① \[등록] 버튼을 클릭하여 학습독려 등록

② 등록 시 학습독려명 기재 (관리자 확인용)

이메일 제목 : 학습독려 이메일 발송 시 제목

기준일 구분 : 학습시작일, 학습 종료일 (-30일\~70일 설정 가능)

진도율 : 0%이상\~100%이하 값에서 필요 값 설정

시험 및 과제 : 필요 값 설정

③ 상태 : 사용으로 체크 되어 있는지 확인

④ SMS / 이메일 선택하여 발송 가능

| 항목       | 학습독려 코드                     | 항목     | 학습독려 코드                                        |
| -------- | --------------------------- | ------ | ---------------------------------------------- |
| 한 칸 띄어쓰기 | <p><br>(이메일 발송 시 입력)</p>    | 이메일    | \{{email\}}                                    |
| 도메인      | \{{domain\}}                | 휴대전화번호 | \{{mobile\_conv\}}                             |
| 사이트 이름   | \{{site\_nm\}}              | 시험점수   | \{{exam\_score\_conv\}}점                       |
| 진도율      | \{{progress\_ratio\_conv\}} | 과제점수   | \{{homework\_score\_conv\}}점                   |
| 회원명      | \{{user\_nm\}}              | 학습기간   | \{{start\_date\_conv\}} \~ {end\_date\_conv\}} |
| 회원 아이디   | \{{login\_id\}}             | 학점     | \{{credit\}}점                                  |

⑤ \[등록] 버튼 클릭하여 등록 완료

### 과정 목록 설정

![](<../../.gitbook/assets/image (77).png>)

① \[학습 독려명] 선택

② \[과정 목록] 탭 선택 후 독려할 과정 추가

③ 등록 되어있는 과정을 선택(교육과정관리 > 과정운영 > 학습독려 탭에서 확인 가능)

④ \[실행] 클릭 시 바로 발송되며, 자동 발송 시 오전 발송됨 (※ 발송되는 시간은 맑은소프트로 문의)

⑤ \[미리보기] 클릭 시 확인 가능할 경우 발송
