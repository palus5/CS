# 정기구독관리

## 정기구독운영

교육상품관리 > 정기구독관리에서 정기구독 교육과정 추가 및 관리할 수 있습니다.

교육과정과 마이크로러닝을 추가하여 정기구독과정을 운영할 수 있습니다.

정기구독은 월별, 일별 구독이 가능합니다.

![](<../../.gitbook/assets/image (86).png>)

![](<../../.gitbook/assets/image (87).png>)

1. 등록된 정기구독 상품 필터 값 설정하여 검색 가능
2.  `[순서저장]` : 드래그 하여 상품의 순서를 변경한 후 해당 버튼 클릭하여 저장

    `[선택상품복사]` : 복사할 상품을 선택한 후 해당 버튼을 클릭할 경우 복사된 상품 확인 가능
3. `[상품등록]` : 클릭 시 상품 등록 가능
4.  상품명 : 정기구독 상품 이름 작성

    표시상품명 : 회원에게 보여질 상품명 작성 (\* 미표기 시 상품명이 학습자 페이지에서 보여짐)

    판매가 : 학습자에게 판매되는 상품의 실제 가격

    구독기간 : 월(月)별 최대 12개월까지, 기간별은 일(日)별 설정 가능

    부가세면세여부 : 면세 여부는 직접 판단해야 하며, 면세가맹점 등록은 PG사에 문의

    간략소개 : 학습자 페이지 정기구독 상품명 하단에 보이는 소개 문구
5. `[등록]` 버튼 클릭하여 등록 완료

### 교육 과정 추가

정기구독 상품 생성 후 교육 과정 추가하는 방법입니다.

![](<../../.gitbook/assets/image (88).png>)

1. 과정을 추가할 ‘구독상품명’ 클릭
2. `[과정관리]` 탭 클릭
3. `[과정추가]` 클릭
4.  개별등록 시

    `[개별 등록]` 탭 클릭 > 추가할 과정 선택 후 `[선택추가]` 버튼 클릭
5.  일괄 등록 시

    `[카테고리별 일괄등록]` 탭 클릭 > 카테고리 선택 > `[선택일괄등록]` 버튼 클릭
6. 드래그 앤 드롭으로 순서 지정 후 `[순서저장]` 버튼 클릭

{% hint style="info" %}
팁 : 정기구독으로만 수강신청 과정(일반 수강신청 불가) 설정 방법\
정기구독 상품에 추가된 과정의 `[과정관리]`탭에서\
'정기구독에서만 판매' 옵션을 사용으로 설정
{% endhint %}

### 마이크로러닝 추가

정기구독 상품 생성 후 마이크로러닝 추가하는 방법입니다.

![](<../../.gitbook/assets/image (89).png>)

1. `[마이크로러닝관리]` 탭 선택
2. `[마이크로러닝추가]` 클릭 후 영상 확인 및 검색
3. 추가할 영상 선택 후 `[선택추가]` 버튼 클릭
4. 등록된 영상을 마우스로 클릭 후 드래그하여 순서 지정 후 `[순서저장]` 버튼 클릭

### 구독자 관리

구독자를 관리하고 확인할 수 있습니다.

![](<../../.gitbook/assets/image (90).png>)

1. `[구독자관리]` 탭 클릭
2. 상태 변경할 구독자(회원) 선택 > 구독중/해지신청/해지완료 선택 > `[변경]` 버튼 클릭 시 상태 변경
3. `[EXCEL]` 버튼 클릭 시 구독자관리 목록 확인 가능
