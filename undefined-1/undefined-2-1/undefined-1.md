# 마이크로러닝관리

## 1. 마이크로러닝 카테고리

교육상품관리 > 마이크로러닝관리에서 카테고리 및 등록된 영상 관리

수강 미신청시에도 등록된 영상 확인 가능합니다.

![](../../.gitbook/assets/image.png)

### 상위 카테고리 등록

카테고리별 영상 관리를 위한 카테고리 등록

![](<../../.gitbook/assets/image (1).png>)

1. ID 우측에 있는 \[바로가기] 버튼 클릭 시 홈페이지의 전체 영상으로 인터넷창 오픈
2. 목록 형태 : 갤러리형 / 웹진형 / 게시판형 선택
3. 정렬 순서 : ‘임의 지정한 정렬순’으로 설정 시 \[순서지정] 버튼 클릭 > 정렬순서지정 창에서 변경
4. 목록갯수 : 홈페이지 과정 리스트에 노출할 목록 개수 설정 후 저장(최대 1,000개까지 가능)
5. \[저장] 버튼 클릭하여 등록 완료
6. \[하위등록] 버튼 클릭 시 상위 카테고리의 하위 카테고리 등록 창이 노출되어 등록 가능

### 하위 카테고리 등록

사용자 사이트 > 마이크로러닝 리스트의 탭별 페이지 화면 설정

![](<../../.gitbook/assets/image (2).png>)

1. \[하위등록] 버튼 클릭 시 카테고리 등록창으로 이동
2. 각 항목별 값 지정 후 등록
   * 목록 형태 : 갤러리형 / 웹진형 / 게시판형 선택
   * 정렬 순서 : 방송일 역순, 등록일 순, 등록일 역순, 방송일 역순, 상위 카테고리에서 임의지정한 정렬순으로 선택가능 (임의 지정한 정렬순의 경우 등록된 드래그하여 순서변경 가능)
   * 시청대상 : \[시청대상추가] 버튼 클릭 시 회원그룹 관리 창 오픈 및 그룹을 선택하여 추가 시 해당 카테고리는 지정된 회원그룹만 시청가능(회원그룹 등록은 회원정보관리 > 회원그룹 관리 참고)
   * 조회수 갱신주기 : 기본 24시간
   * 순서 : 카테고리 노출 순서 설정
3. 내용 입력 후 \[등록] 버튼을 클릭하여 저장 완료

## 2. 마이크로러닝 관리

### 마이크로러닝 영상 등록하기

![](<../../.gitbook/assets/image (3).png>)

1. 필터를 활용하여 검색, 원하는 조건에 부합하는 카테고리 값 조회
2. \[등록] 버튼 클릭 시 마이크로러닝 등록 페이지로 이동
3. 각 항목 내용 기입 (\*는 필수 기입 사항)
   * \[기존강의선택] 버튼 클릭 시 콘텐츠 관리에 등록된 영상 등록
   * \[신규강의등록] 버튼 클릭 시 온라인 강의 관리 팝업창 오픈되어 신규 등록 후 현재 페이지에서 해당 영상 등록
   * 추천여부 : 선택 시 좌측 상단에 라벨 등록
   * 오픈일 : 오픈일 시간 지정
   * 노출만료일 : 영상 노출 만료일자 지정 가능, 사용 또는 미사용 선택 (사용 시 날짜 지정 )
   * 영상 길이 : 입력 시 썸네일 우측 하단에 표기
   * 링크 : 사용으로 선택 시 콘텐츠 다운로드나 참고용 링크 삽입 가능
   * 댓글 사용여부 : 등록 시 영상 하단에 댓글 등록 가능
   * 시청대상 : 선택 시 해당 그룹만 영상 노출
   * 노출여부 : ‘노출’ 또는 ‘중지’ 확인 후 설정
   * 상태 : ‘정상’ 또는 ‘중지’ 확인 후 설정
4. \[등록] 버튼 클릭하여 마이크로 영상 등록

### 영상 수정 및 시청 이력 조회하기

![](<../../.gitbook/assets/image (4).png>)

1. \[카테고리수정] : 수정할 방송 선택 후 \[카테고리수정] 버튼을 클릭하여 뜨는 창에서 수정
2. 제목 선택 시 상세 페이지 이동
3. 방송정보 탭 : 해당 영상의 상세정보 확인 및 수정
4. 수정할 내역 확인 후 \[수정] 버튼 클릭하여 완료

![](<../../.gitbook/assets/image (5).png>)

5. 시청이력 탭 : 해당 영상을 시청한 회원 정보 확인 가능
6. 필터값 활용하여 검색 가능
7. 전체 시청내역보기,  회원별 시청내역보기로 목차 확인
8. 회원 아이디 선택 시 해당 회원의 CRM창 이동

## 3. 마이크로러닝 메인관리

운영자가 추천하는 영상을 그룹으로 묶어 홍보할 수 있는 ‘추천 마이크로러닝’ 페이지를 설정할 수 있습니다.

![](<../../.gitbook/assets/image (6).png>)

1. \[등록] 버튼 클릭하여 그룹 제목을 등록
2. 리스트를 드래그하여 노출 순서 설정이 가능, 순서 조정 후 \[순서저장] 버튼을 클릭하여 완료
3. 제목 클릭 시 제목 수정 가능
4. \[영상목록] 버튼 클릭하여 영상 등록
5. \[영상추가] 버튼을 클릭하여 영상추가
6. 리스트를 드래그하여 영상 노출 순서 설정
7. 미노출 할 영상은 선택 후 \[선택삭제] 버튼을 클릭하여 삭제
