## 과정카테고리

교육상품관리 > 과정카테고리에서 카테고리의 상, 하위를 설정 및 수정이 가능합니다.

설정한 과정 카테고리는 사용자 사이트의 과정 리스트 페이지에서 노출됩니다.

![](<../../.gitbook/assets/image (98).png>)

#### 최상위 카테고리 설정

사용자 사이트 > 과정 리스트의 전체과정 탭 페이지 화면 설정

![](<../../.gitbook/assets/image (99).png>)

1. ID 우측에 있는 \[바로가기] 버튼 클릭 시 홈페이지의 전체과정으로 인터넷창 오픈
2. 과정목록 타입 : 리스트형 / 갤러리형 선택
3. 과정 정렬순서 : 등록일순 / 등록일 역순 / 수강신청일 순 / 수강신청일 역순 등 선택
4. 목록갯수 : 리스트에 노출할 목록 개수 설정 가능
5. 카테고리 내용 설정 후 \[저장] 버튼 클릭 시 등록 완료
6. 과정 정렬 순서 중 ‘임의저장한 정렬순’ 선택 시 과정 목록의 과정명을 드래그하여 순서 지정 후 \[순서저장] 버튼 클릭

#### 상/하위 카테고리 등록

※ 사용자 사이트 > 과정 리스트의 탭별 페이지 화면 설정

![](<../../.gitbook/assets/image (100).png>)

1. \[하위등록] 버튼 클릭 시 카테고리 등록창으로 이동
2.  카테고리 등록 항목은 최상위 카테고리와 동일하게 등록

    ※ 단, 상위 카테고리, 카테고리명, 메뉴노출 여부, 순서 추가 설정
3. 카테고리별로 리스트에 노출할 항목(학습기간, 수강료, 강사명 중) 선택 가능
4. 내용 입력 후 \[등록] 버튼을 클릭하여 저장 완료

\* 카테고리 등록 시 좌측 카테고리 영역에 추가 및 카테고리 명을 클릭하여 설정 값 수정 가능

3. \[선택복사] 버튼 클릭 시 이미 등록된 과정을 선택하여 복사가 가능
   * 온라인 상시과정일 경우 온라인 상시과정으로만 복사

#### 과정/패키지 등록 > 과정정보 탭

**1. 과정정보 탭 > 기초 정보 입력**

![](<../../.gitbook/assets/attachment54aa823d e64b 428e a08d 7653b615e502image.png>)

1. 과정 구분 선택 : 과정 타입에 따라 2번 영역의 입력 항목이 상이, 과정 타입 안내 참조
2.  값 입력 (\* 필수 입력 사항)

    과정 카테고리, 과정 개설명 등록

    메인 이미지 권장 사이즈 : 이미지 크기 770\*539 px

    학습 일수 : 상시 과정의 경우 학습 일수 설정 (수강신청 시 학습 일수만큼 수강 가능)
3.  수강료 노출 타입 설정

    정가로 운영 시 : 정가에 0원을 입력, 수강료에 금액을 입력

    무료로 운영 시 : 0원, 무료, 미노출 중 선택 가능

    월 가격으로 운영 시 : 정가, 수강료(실제 결제 금액) 입력 후 월 선택 및 월별 가격을 입력\
    ※ 월 가격의 경우 리스트에 월 가격으로 노출되나, 회원 결제 시 수강료 입력 금액으로 결제됨
4.  홍보 문구 설정

    이벤트 문구 : 홍보 문구 입력 시 판매 페이지 과정명 상단에 노출

    라벨 설정 : 섬네일 이미지에 라벨형태로 홍보 문구 노출 가능(라벨 색상 등록 가능)
5.  부가세 및 할인 여부 설정

    부가세면제여부 : 원격평생교육원 신청 시 부가세면세여부를 ON으로 설정 가능\
    (＊영수증 표기용으로 면세여부는 직접 판단하셔야 하며, PG사에 추가 설정이 필요할 수 있음)

    그룹 할인 적용 여부 : ON의 경우 그룹핑한 그룹의 회원들은 할인된 가격으로 과정 신청 가능
6. 포인트 사용 여부 : 포인트 기능 사용 시 포인트정책의 교육과정별 정책 적용여부 설정

![](<../../.gitbook/assets/attachmentfee917ea 5c7a 41a8 9818 525706dd4800image.png>)

\*연장 및 일시정지는 상시 과정에 한해서 사용 가능합니다.

7.  연장 기능 사용 시

    수강생이 수강연장 신청 시 설정된 연장 비용으로 해당 과정의 입력한 연장일수 만큼 연장이 가능함 (그룹 할인 적용됨)
8.  일시정지 기능 사용 시

    온라인 상시과정에 한하며, 관리자가 지정한 횟수 혹은 기간만큼 수강중 일시정지가 가능

    최대일시정지횟수 혹은 일시정지기간 둘 중 하나를 충족하면 일시정지 기능을 더이상 사용 불가\
    (예시 : 횟수 2회 / 기간 30일 설정 → 1회 일시정지 사용한 후 30일이 지나면 일시정지 사용 불가함)

    회원 CRM 창에서 학습자의 일시정지 이력확인 가능

    일시정지 기간 동안은 학습독려 발송되지 않음

    학습자는 일시정지 기간에 ‘일시정지 해제’가 가능, 해제 즉시 다시 수강할 수 있음

![](<../../.gitbook/assets/attachment4b8de65f ae94 49fc b730 ad4d5a147f01image.png>)

9. 샘플강의 : 맛보기 강의로 확인 가능
10. 과정에 교재도서/옵션상품 설정 가능

    \[도서추가] 및 \[상품추가]하여 항목 추가 가능

    도서 및 상품의 정보 확인 가능

    필수 지정 시 과정 구매 시에 해당 도서/상품 필수 구매

    순서 지정 후 \[순서저장] 클릭해 순서 변경

![](<../../.gitbook/assets/attachment86aa98ff 3705 4c74 9e9c 789c66d8c4a5image.png>)

11. 주문메모 사용여부 : 회원이 주문 결제창에서 별도의 요청 사항을 메모할 수 있도록 설정하는 기능

    모바일 지원 : 모바일 기기에서도 학습할 수 있도록 지원하는 기능

    오픈 알림: 강의 오픈 시 알람을 받길 원하는 회원이 알림 신청 수집 여부 설정 가능
12. 수강신청완료 알림: (\*알림톡 사용 시에만 사용 가능) 수강신청 완료 시 카카오톡으로 알림을 발송 /\
    알림톡 템플릿을 생성하여 과정별로 다른 카카오톡 메시지 발송 가능
13. 판매여부 : 비활성화 시 수강신청이 불가능\
    노출여부 : 비활성화 시 과정 목록에 노출되지 않음

**2. 과정 설명 입력**

과정 설명을 입력하는 곳으로 과정에 대한 소개를 작성할 수 있습니다.

![](<../../.gitbook/assets/image (105).png>)

1. 과정 목록 소개 문구 : 과정 목록에서 2\~3줄까지 노출되는 간략 소개 문구
2. 과정소개 : 과정에 대한 소개를 작성합니다. (사용자 사이트의 과정 상세 페이지 내 확인 가능)
3. 링크 삽입 및 이미지 삽입이 가능합니다.
4. 학습목표 : 학습목표를 작성합니다. (사용자 사이트의 과정 상세 페이지 내 확인 가능)
5. \[등록] 버튼 클릭 시 완료됩니다.

※ 초기 과정 등록 시 노출 숨김, 판매 중지 상태로 등록되며, 과정 개설 리스트에서 과정명을 클릭하여 추가 정보(운영정보/강의목차/평가 정보 등) 등록한 후 정상 상태로 변경해야 함

* 초기 등록 후 ‘기초 정보’ 하단에 판매여부, 노출여부 항목이 노출되어 상태값 수정 가능

**3. 과정정보 탭> 기초정보 추가**

![](<../../.gitbook/assets/attachment2e4fad76 c7f8 496f ad5a daf088012128image.png>)

1. 개설된 과정명 선택 시 세부적인 과정정보 설정 가능
2.  태그 : 입력 시 과정 목록 페이지에서 입력한 태그 정보가 노출,

    홈페이지 우측 상단 검색을 통해 태그 검색 가능
3.  샘플강의 : 샘플 강의 등록 시 과정 판매 페이지에서 맛보기로 샘플 영상 확인

    \[도서추가] 시 교육과정관리 > 도서관리 등록된 교재 추가 가능

    \[상품추가] 시 마켓관리 > 상품관리에 등록된 상품 추가 가능

    \[담임강사추가] 시 과정 목록에 강사명이 표기되며, 강사 페이지에서 과정 목록으로 노출
4.  교육일정 등록 여부 : ON으로 설정 시 교육 일정 페이지에 노출

    ※ 등록 시 학습 시작일에 교육 일정 페이지에 노출되며, 상시 과정일 경우 학습 시작일이 없어 교육일정 등록이 되지 않음

**4. 과정정보 탭 > 운영정보 등록**

운영정보 탭은 과정을 등록한 후 수정 화면에서 설정할 수 있습니다.

![](<../../.gitbook/assets/attachment22a3e4ba 2186 4a11 806d 0a4d39641709image.png>)

1.  신청즉시 승인 : \[ON] 선택 시 수강신청 후 바로 강의실 입장 가능

    결제여부 확인 후 승인 희망 시 \[OFF]로 설정 + 승인대기 수강자가 있을 경우 알림 받을 메일 주소 입력 가능
2.  수강신청대상 : \[ON] 선택 시 그룹핑한 특정 회원을 대상으로 수강 허용

    회원정보관리 > 회원그룹관리에서 생성 후 \[추가] 버튼 클릭하여 대상 등록
3. SMS 인증 : 수강 시 마다 회원정보에 등록된 휴대전화로 SMS 인증 받는 기능
4.  자동수료처리 : \[ON] 선택 시 진도율과 객관식 시험에만 자동수료처리 적용

    서술형 시험, 과제, 토론 등의 항목이 평가항목에 포함될 경우 \[OFF]로 설정
5.  복습허용 : 학습기간 종료 후 복습을 허용하는 기능 (단, 복습기간에는 진도율 체크는 되지 않음)

    학습제한 : 1일 학습할 수 있는 차시를 제한하는 기능

    배수제한 : \[ON] 선택 시 한 차시에 학습량을 제한하는 기능으로 강의 최대 시간을 설정

    배수제한은 차시별로 개별 적용되며, 배수제한 시간 초과 시 다음 접근이 불가

    ex) 60분 강의의 배수를 2배로 설정한 경우, 총 120분을 학습
6.  인원제한 : \[ON] 선택 시 입력한 수만큼 수강인원 제한

    결제 진행중인 인원이 포함되므로, 실제 제한 인원보다 여유롭게 설정
7.  배속재생 : \[ON] 선택 시 강의를 배속으로 수강하지 못하도록 제한할 수 있으며,

    콜러스 플레이어를 사용하는 차시에만 적용

    맑은소프트에 문의 후 추가 설정 가능 (기본 제공되지 않음)
8.  탐색제한 : \[ON] 선택 시 학습하지 않은 영상은 뒷부분을 먼저 들을 수 없도록 차단

    강의순차학습 : 순차적으로 학습할 수 있도록 설정하는 기능

![](<../../.gitbook/assets/attachment09aad3dd d17e 410a bf8e 16ff322ddf30image.png>)

1.  차시별학습기간 : \[ON] 선택 시 차시별로 학습기간을 지정할 경우 사용

    단, 상시과정을 제외한 과정에서 사용 가능

    강의 목차에서 차시별로 학습기간 설정
2.  과정모듈 : 사용할 과정 모듈을 설정하는 기능으로, 시험, 과제, 토론, 설문, 수강후기 등

    \[ON]으로 설정할 경우 수강 페이지에 메뉴가 노출되어 서비스 이용이 가능

    과정 수료증 및 수강증 사용 시 ON으로 설정

    \*홈페이지 관리 > 사이트 관리 > 사이트정보에서 수강증 배경 이미지 등록

    \*하단의 수료증 정보에서 수료증 상세 설정 가능

![](<../../.gitbook/assets/attachment6da6e499 d395 4896 8d7b fd3211db8e67image.png>)

1.  선행과정 : 선행과정으로 등록한 과정을 먼저 수료한 후 현재 등록중인 과정의 수강신청이 가능하도록 설정하는 기능

    \[선행과정 추가] 버튼을 클릭하여 선행 과정으로 설정한 과정을 선택

    \[과정담당자추가] 버튼을 클릭하여 과정 담당자 추가

    강사를 과정 담당자로 지정 시 과정 운영자로 추가한 후 과정 담당자로 설정

    ※ 과정운영자 콘텐츠 등록 및 관리는 콘텐츠관리 > 온라인강의관리 > 등록된 콘텐츠에 담자 지정 이후에 가능합니다.

1.  배점비율 : 총점을 계산할 배점 설정. (총점 100점 만점 기준으로 평가항목의 점수 입력)

    자동수료처리 시 출석, 객관식 시험점수로만 수료기준 기입

    \*자동수료처리 : 과정개설의 과정정보 탭 > 운영정보의 ‘자동 수료처리‘ ON으로 설정
2.  수료/과락 기준 : 총점, 진도율 2개 항목으로 수료/과락 기준 설정 가능\
    총점 입력 시 배점 비율 부여한 100% 기준으로 총점 기입

    예시1) 시험점수 70점 이상, 진도율 80%이상을 수료처리 하고자 할 때

    > \> 배점비율: 시험 100% + 총점: 70점 + 진도: (출석)율 80%로 설정

    예시2) 총점 계산 시 진도율 50%, 시험40%, 과제 10%로 설정하고, 총점이 60점 이상이며 진도율은 75%이상을 수료처리 하고자 할 때

    > \> 배점비율 : 진도율50%, 시험40%, 과제 10% + 총점: 60점 + 진도(출석)율 75%로 설정
3.  설문참여 필수여부 : \[ON] 선택 시 모든 설문을 참여해야 수료 기준에 충족됨

    설문참여 독려 기능 : \[ON] 선택 시 진도기준을 충족한 수강생에게 설문참여를 독려하는

    알림창 노출
4. 수료기준 노출여부 : \[ON] 선택 시 사용자단 과정 상세 페이지에서 수료기준 확인 가능

#### 1. 수강생 탭

수강생 탭 : 수강생 관리 및 진도율, 학습기간, 결제금액 등 수강생별 상태 확인할 수 있습니다.

![](<../../.gitbook/assets/attachment34b13fee 1cc2 49ac 81f3 18e9f35b11edimage.png>)

1.  \[수강생 등록] : 클릭 시 수강생 등록창에서 수강생을 선택하여 입과 처리

    \[검색 결과 전체등록] 버튼을 클릭하여 검색되어진 모든 회원 일괄등록 가능

    \[선택등록] 수강생 목록에서 수강생을 선택하여 등록 가능

    \[일괄 등록] : 다수의 수강생을 일괄 등록하고자 할 경우 제공되는 샘플 양식을 다운받아

    내용 작성 후 업로드하여 입과 처리
2.  \[학습기간 일괄수정] : 수강생의 학습기간을 일괄 수정하는 기능, 최대 365일까지 학습종료일 연장/단축

    상시 과정에만 해당 버튼 노출 되며, 수강생 선택 또는 미선택으로 수정 가능

    정규과정의 경우 과정정보 탭 > 기초 정보의 학습기간 항목에서 기존 수강생 학습기간 수정 가능
3. 수강생의 상태를 변경 가능 : 수강생 선택 후 상태 값 선택하여 \[변경] 버튼 클릭하여 적용
   * 정상상태 : 강의실에 입장하여 수강이 가능한 상태
   * 승인대기 : 관리자가 수강생을 정상으로 변경 후 강의실 입장
   * 입금대기 : 수강생이 무통장입금을 신청한 상태로 ‘수강대기’ 상태와 동일함
   * 취소요청 : 수강생이 환불신청을 한 생태로 수강은 가능 (환불요청 상태)
   * 수강취소 : 결제여부와 무관하며, 수강자 또는 관리자가 수강을 취소한 상태

진도/출석 탭 : 강의 세부내용 조회 및 완료자 인원 수, 진도율 확인이 가능합니다.

1. 과제명 클릭 시 제출한 수강생을 확인할 수 있으며,
2. \[평가하기] 버튼을 클릭하여 과제 평가 처리
   * 개인별 과제 내용 확인 후 점수와 평가 의견을 기입하고 \[평가하기] 버튼을 클릭하여 평가 완료
3. \[제출취소] : 평가 전 취소 가능, 응시생 재시험 가능
4. \[성적분포] : 클릭 시 해당 과제의 정보 및 응시현황 등 확인

#### 7. 토론 탭 > 토론 추가

해당 과정에 토론을 추가할 수 있습니다.

![](<../../.gitbook/assets/attachment8ce0120f 1d06 4f94 b2b6 87f9620fae71image.png>)

1.  \[토론추가] 버튼을 클릭하여 추가할 토론 \[선택] 버튼 클릭

    토론추가 : 콘텐츠 관리 > 과제관리 > 토론관리에서 토론 등록 후 추가

    (콘텐츠 관리 > 과제관리 매뉴얼 참고)
2.  토론추가 후 토론명이 생성 되어 정보 확인 (상시과정 제출강의, 정규과정 제출기간이 표기됨)

    공개일 : 토론공개일 등록 가능하며, 미등록 시 등록 후 바로 노출 됨

    제출기간 : 상시과정의 경우 제출기간 ’00’강의 이후로 설정 / 정규과정의 경우 제출기간 설정

    배점 : 배점 비율에 토론 점수가 70점일 경우 토론 1개 등록 시 배점 설정은 70점, 2개 등록 시

    30점, 40점 혹은 35점, 35점 등 총 합이 70점이 되도록 등록

    성적분포 : 성적 분포 확인 가능
3. \[삭제] 버튼 클릭 시 삭제 여부 알림창이 오픈되어 토론 삭제가 가능

#### 8. 토론 탭 > 토론 채점

토론을 평가하고 채점할 수 있습니다.

![](<../../.gitbook/assets/attachment3bbdd6d1 c6d4 4fa0 8d8b 01f72da51f8bimage.png>)

1. 토론명 클릭 시 제출한 수강생 확인이 가능
2. \[펼치기] 버튼 클릭 시 등록한 토론 정보를 확인할 수 있음
3.  \[평가하기] 버튼을 클릭하여 토론 평가 처리

    \[평가내역] 버튼을 클릭하여 개인별 토론 내용 확인 후 점수와 평가의견을 기입하고 \[등록] 버튼을 클릭하여 평가 완료
4. \[참여취소] : 평가 전 취소 가능

#### 9. 설문 탭 > 설문 추가

해당 과정에 설문을 추가할 수 있습니다.

![](<../../.gitbook/assets/attachment71dabe18 5e10 4cc4 9170 5048b356ce72image.png>)

1. \[설문추가] 버튼을 클릭하여 추가할 설문을 선택
2.  설문추가 후 설문명이 생성 되어 정보 확인 (상시과정 제출강의, 정규과정 제출기간이 표기됨)

    설문명 : 클릭 시 설문 결과에 대한 내역 확인 가능

    참여기간 : 상시과정의 경우 참여기간 ’00’강의 이후로 설정 / 정규과정의 경우 참여기간 설정

    설문추가 : 콘텐츠 관리 > 설문관리에서 문항과 설문지 등록 후 추가

    (콘텐츠 관리 > 설문관리 매뉴얼 참고)
3. \[삭제] 버튼 클릭 시 설문 삭제가 가능

#### 10. 설문 탭 > 설문 결과

![](<../../.gitbook/assets/attachmentcbf5a5ef 6141 4471 a78c d3939e3f08fbimage.png>)

1. 설문명 클릭 시 설문 결과를 확인할 수 있으며, 각 설문 문항별 응시 비율 확인이 가능
2. \[응시상세보기] 버튼 클릭 시 수강생 답변 및 상세 정보 확인 가능
3. \[개별응답 EXCEL] 버튼 클릭 시 수강생 답변 및 상세 정보 엑셀 다운 가능

#### 11. 자료 탭 > 자료추가

해당 과정의 자료를 추가할 수 있습니다.

과정 내 등록된 자료는 사용자>마이페이지> ‘강의실 입장’ 시 강의자료 메뉴에서 확인할 수 있습니다.

![](<../../.gitbook/assets/attachmentb446c45a 8adc 4082 b933 c4c97d929493image.png>)

![](<../../.gitbook/assets/attachment0e08d4c4 1591 4e88 9fc7 6c15f6a425adimage.png>)

1.  \[자료추가] 버튼을 클릭하여 추가할 자료를 선택

    자료추가 : 콘텐츠 관리 > 콘텐츠 관리 > 자료 관리에서 등록 후 추가

    (콘텐츠 관리 > 콘텐츠 관리 매뉴얼 참고)
2.  자료추가 후 자료명이 생성 되어 정보 확인

    공개일 : 설정 시 공개일 이전에는 수강생에게 비노출

    파일명 : 클릭 시 해당 자료 다운로드 가능
3. 콘텐츠 관리에서 등록한 자료를 링크로 삽입했을 경우 클릭 후 해당 링크로 이동 가능
4. \[삭제] 버튼 클릭 시 삭제 가능
5. 순서 부분을 드래그하여 순서 조정 가능
6. 순서 조정 후 \[저장]클릭하여 자료 순서 저장

#### 12. 게시판 탭

해당 과정의 게시판 설정 및 관리를 할 수 있습니다.

![](<../../.gitbook/assets/attachment3da363c8 c0a6 4ca7 a540 3436c64b30f7image.png>)

1. 게시판 탭 클릭
2.  셀렉트 박스 선택하여 게시판 별 리스트 확인 가능

    공지사항 : 관리자가 해당 과정에 대한 공지사항 등록

    Q\&A : 제목 선택 시 질문 상세 내용 페이지로 이동 및 관리자 답변 처리

    수강후기 : 댓글 기능 사용 가능, 홈페이지에서 댓글 등록 (맑은소프트 문의)

    자유게시판 : 수강생의 글에 댓글 등록 가능 , 홈페이지에서 등록 및 확인
3. 제목 선택 시 등록된 글의 세부 내용 확인
4. \[수정], \[삭제] 버튼을 클릭하여 게시글을 수정하거나 삭제 가능

#### 13. 성적관리 탭

해당 과정의 성적 확인 및 점수 재산정 처리

![](<../../.gitbook/assets/attachmentaa7ea6aa 62d3 4882 9533 c115d644d311image.png>)

1. 해당 과정의 수료여부, 마감여부 선택 후 회원명, 회원 아이디로 검색
2.  \[진도율재산정] : 해당 과정의 전체 수강생 진도율 재산정

    \[전체 성적 재산정] : 해당 과정의 전체 수강생 성적 재산정

    \* 진도율 재산정, 전체성적재반영은 전체 수강생 대상으로 재산정됨
3. 기타 점수 입력 시 기재 후 \[성적 재산정] 버튼을 클릭하여 반영 처리

#### 14. 수료관리 탭

해당 과정의 수료 여부 처리 및 수료증 출력이 가능합니다.

![](<../../.gitbook/assets/attachmentbefb9d24 250c 4e2b 8a64 6480fea058feimage.png>)

1. \[펼치기] 버튼 클릭 시 과정 정보 및 배점 비율 표시
2. 해당 과정의 수료여부, 과정 종료여부 선택 검색
3. 수강생별 성적확인 및 수료 확인 (평가 미달 시 붉은색으로 영역 표기)
4. \[수료번호재부여] 버튼 클릭 시 기본형식으로 수료번호를 재부여
5. \[수료증일괄출력] 버튼 클릭 시 수료증을 일괄로 출력 가능
6.  회원의 수료 상태를 수동으로 처리 가능하며, 수동 수료 판정 시 수강생 선택 후 작업 선택의 항목을 클릭하여 처리(미달된 항목 없는 경우도 수료판정 가능)

    선택수료판정 : 선택 수강생 수료여부 판정 (미달시 미수료 판정)

    선택판정취소 : 선택수강생 수료여부 판정 취소

    전체수료판정 : 전체 수강생 수료여부 판정 (미달시 미수료 판정)

    전체판정취소 : 전체 수강생 수료여부 판정 취소

    선택종료처리 : 미판정된 수강생 종료 처리 시, 미수료로 변경됨 (판정 후 미판정으로 복구불가)

    선택종료취소 : 종료 처리된 수강생을 미종료 상태로 변경

    전체종료처리/전체종료취소 : 선택 종료, 판정 처리와 동일 하며 전체 수강생 대상
7. \[수동수료] 버튼 클릭 시 수동수료 처리에 대한 사유 작성 후 처리 수동 수료 완료 가능
8. \[수료증] 버튼 클릭 시 개별 수료증 출력 가능
