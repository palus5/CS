# 관리자(운영자)

### 관리자 페이지

* 설정한 이러닝 사이트의 도메인 주소가 곧 사용자단의 메인 주소로 관리자단은 사용자단 주소 뒤에 /sysop 을 입력하여 접근합니다.
* 예) [**https://stdemo.malgnlms.com/sysop**](https://stdemo.malgnlms.com/sysop)/index.jsp

<figure><img src="../../.gitbook/assets/image (108).png" alt=""><figcaption></figcaption></figure>

### 관리자단 접속

* **사용자단 주소/sysop** 으로 접속 시 로그인 화면으로 이동 및 기본 제공되는 admin 계정으로 로그인 후 비밀번호를 변경하여 이용하면 됩니다.
* 기본 제공 admin 계정 외 추후 개별적으로 생성한 관리자 계정으로도 로그인 가능합니다.
