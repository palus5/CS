# 회원관리

> 전체 회원 데이터의 단일 기준점(SSOT)으로, 유형을 가리지 않고 모든 회원을 한 목록에서 조회·관리합니다. 각 회원의 **수강정보·회원정보·회원이력**을 한곳에서 확인하는 CRM 창의 출입구이며, 회원 등록·일괄 처리·발송의 시작점입니다.

***

## 화면

***

## 회원 등록 방법 3가지

| 방법       | 위치           | 설명                  |
| -------- | ------------ | ------------------- |
| **회원가입** | 사용자단         | 회원이 직접 가입 절차를 거쳐 등록 |
| **등록**   | 관리자단 \[회원관리] | 관리자가 1명씩 개별 등록      |
| **일괄등록** | 관리자단 \[회원관리] | 엑셀 양식으로 대량 등록       |

***

## 주요 기능

| 기능            | 설명                                      |
| ------------- | --------------------------------------- |
| **검색**        | 회원유형, 상태, 가입일, 회원소속, 회원등급, 키워드로 필터링 검색  |
| **상태변경**      | 회원 선택 후 상태(정상/중지) 일괄 변경                 |
| **소속변경**      | 회원 선택 후 소속 일괄 변경                        |
| **메일/SMS/쪽지** | 선택 회원에게 메일·SMS·쪽지 발송 (SMS는 부가서비스 별도 신청) |
| **EXCEL**     | 전체 회원 목록 엑셀 다운로드 (개인정보 조회이력 기록됨)        |
| **일괄등록**      | 엑셀 양식으로 회원 대량 등록                        |
| **일괄갱신**      | 엑셀 양식으로 회원 정보 대량 수정                     |
| **등록**        | 개별 회원 등록                                |

***

## 사용 방법

### 회원 목록 조회

① 회원유형, 상태, 가입일, 소속, 등급, 키워드를 설정하고 **\[검색]** 버튼을 클릭합니다.

② 컬럼 제목을 클릭하면 해당 컬럼 기준으로 오름차순/내림차순 정렬됩니다. (No·휴대전화 컬럼 제외)

③ 목록 행의 각 항목을 클릭하면 관련 화면으로 바로 이동합니다.

| 클릭 항목     | 이동 화면                |
| --------- | -------------------- |
| **회원명**   | CRM 창 (회원 통합 관리)     |
| **휴대전화**  | SMS 발송 창 (해당 회원 선택됨) |
| **이메일**   | 메일 발송 창 (해당 회원 선택됨)  |
| **수강 건수** | 통합수강생관리 페이지          |
| **실제금액**  | 주문목록 페이지             |

### 회원 일괄 등록

{% stepper %}
{% step %}
## **\[일괄등록]** 버튼을 클릭합니다.
{% endstep %}

{% step %}
## **\[샘플양식 다운로드]** 버튼을 클릭한 후 양식에 맞게 내용을 작성합니다.

(회원소속 아이디는 회원관리 > 회원소속관리에서 확인 가능)
{% endstep %}

{% step %}
## 회원소속을 선택하고, 필요 시 **고객사 소속코드 사용**을 체크합니다.

(이전 사이트에서 쓰던 소속코드로 연동 등록)
{% endstep %}

{% step %}
## **\[파일선택]** 버튼을 클릭하여 작성한 엑셀 파일을 업로드합니다.
{% endstep %}

{% step %}
## **\[미리보기]** 버튼으로 등록될 회원을 확인합니다.
{% endstep %}

{% step %}
## **\[등록하기]** 버튼을 클릭하여 완료합니다.
{% endstep %}
{% endstepper %}

### 회원 일괄 갱신

{% stepper %}
{% step %}
## **\[일괄갱신]** 버튼을 클릭합니다.
{% endstep %}

{% step %}
## 갱신 대상 회원소속을 선택합니다.
{% endstep %}

{% step %}
## **\[샘플양식 다운로드]** 버튼을 클릭한 후 엑셀 파일에서 수정 내용을 작성하고 저장합니다.
{% endstep %}

{% step %}
## **\[파일선택]** 버튼을 클릭하여 수정한 엑셀 파일을 업로드합니다.

(아이디·회원아이디·성명은 변경 불가)
{% endstep %}

{% step %}
## 데이터 검증 결과를 확인합니다.

부적합 데이터가 있으면 **\[초기화]** 버튼 클릭 후 파일 수정 재업로드합니다.
{% endstep %}

{% step %}
## 검증 완료 후 **\[일괄등록]** 버튼을 클릭합니다.
{% endstep %}
{% endstepper %}

## CRM 창 (회원명 클릭 시)

목록에서 **회원명**을 클릭하면 해당 회원의 모든 활동을 한 화면에서 관리하는 CRM 창이 열립니다.

| 탭        | 내용                               |
| -------- | -------------------------------- |
| **수강정보** | 수강 중인 과정·진도율 확인, 개별완료처리, 학습기간 수정 |
| **회원정보** | 가입 정보 확인·수정, 비밀번호 변경, 회원등급 확인    |
| **회원이력** | 과정학습·방송시청·다운로드·접속 등 세부 이력        |
| **주문**   | 교육과정·상품 주문내역                     |
| **쿠폰**   | 보유 쿠폰 및 사용내역                     |
| **포인트**  | 보유 포인트 및 사용내역                    |
| **Q\&A** | 게시판 Q\&A 내역                      |
| **발송**   | 메일·SMS 발송내역                      |

{% hint style="info" %}
**상담등록**: CRM 창에서 회원과의 상담 내역을 기록·관리할 수 있습니다. 등록한 상담은 숨김 처리만 가능하며 수정·삭제는 불가합니다.
{% endhint %}

{% hint style="warning" %}
**EXCEL 다운로드**는 휴대폰·이메일 등 개인정보가 포함되며, 다운로드 시 **개인정보 조회이력**에 기록됩니다. 불필요한 다운로드는 자제하세요.
{% endhint %}
